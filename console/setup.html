AI 연결 상태

계정 로그인 버튼을 누르면 공식 CLI 로그인 창이 열립니다. 아이디·비밀번호·인증 코드는 열린 터미널과 공식 브라우저에서 직접 입력하세요.

앱은 로그인 정보와 인증 코드를 받거나 별도로 저장하지 않습니다. 이미 로그인된 계정은 각 CLI에서 관리하며 자동으로 로그아웃하지 않습니다.

역할 배정

역할 변경은 작업 화면에서 진행하세요. 같은 AI가 구현·검수를 맡으면 독립성 경고가 표시됩니다.

확인할 항목

      진단 보고서에는 계정 이메일, 인증 토큰, CLI 원문 출력, 프로젝트 코드와 경로를 포함하지 않습니다.

      이 점검은 실제 AI 작업 성공·잔여 사용량·요금을 보장하지 않습니다. Antigravity의 로그인은 CLI에서 직접 확인해야 합니다.
