AI DEV DIRECTOR macOS Preview 0.3.6 — GROK PROCESS INTEGRATION

HUD 우측 상단에 Grok 보조 분석·리서치 카드를 추가했습니다.
카드를 누르면 질문 입력, 공식 CLI 계정 로그인, 연결 확인, 분석 요청·취소와 결과·출처 표시를 사용할 수 있습니다.
기존 HEAD·BUILDER·REVIEWER 역할은 유지합니다. Grok은 별도의 RESEARCH 호출로 기록합니다.

공식 Grok CLI의 --prompt-file 및 JSON 출력으로 연결합니다.
웹 검색과 문서 조회 도구만 허용하고 read-only 샌드박스를 사용합니다.
질문은 임시 파일로 전달하며 사용자 프로젝트 파일을 자동 첨부하지 않습니다.
API 키 환경변수를 제거하고 기존 CLI 인증을 사용합니다. 계정 로그인은 사용자가 완료합니다.
인증 정보, CLI 인증 원문, 사용자 실행 기록은 배포본에 포함하지 않습니다.
로컬 Host/Origin·인증 토큰 검사, 요청 크기와 ID 제한, 중복 요청 방지, 개별 취소를 적용했습니다.

0.3.2 당시 자동 검사 55개와 브라우저의 카드·분석 창·결과·출처 링크를 확인했습니다.
설치된 Grok CLI 1.0.46에서 공개 연결 확인 질문의 실제 JSON 응답을 확인했습니다.
기존 앱·엔진 백업과 사용자 설정·데이터 보존 방식을 유지합니다.
Apple 개발자 서명·공증은 없습니다.

0.3.2 설치본에서 실제 Grok 웹 문서 조사 완료·출처 URL 포함 결과와 CLI 연결 확인 버튼을 확인했습니다.

0.3.3 HUD 변경: Grok 입자 구체·코어 스트림·구체 위치 카드, 상태 색/활동량 연동, 모션 끄기에서도 상태 갱신, WebGL2/2D 지원.

0.3.3 검증: 관련 pytest 64개 통과. hud_renderer.cjs (네 번째 노드·스트림, 3역할 독립 상태, WebGL/2D, 모션 끄기), grok_hud.cjs (실행/완료/오류/오프라인 복구) 통과.

0.3.4: HUD 연결 상태를 연결됨/연결 안됨/확인 필요로 구분하고 사유·시각·다시 점검 버튼을 추가했습니다. 최근 실제 응답은 10분 이내 기록만 사용하며, 미로그인이나 미설치 등 명시적 실패가 있으면 이전 성공 기록으로 덮어쓰지 않습니다. 새로고침은 유료 AI 생성을 수행하지 않습니다.

0.3.5: 4개 AI의 7갈래 회로 버스·이동 광점·발광 접점, 시안/보라색 코어 광륜과 구면 회로, 다층 파동·투영 링·패널 조명을 추가했습니다. 대기는 은은하게, 작업 중에는 더 빠르고 밝게 반응합니다. WebGL/2D 모두 지원하며 모션 끄기는 입자와 CSS 조명을 정지합니다. 기존 연결 상태와 AI 역할/설정은 유지합니다.

0.3.6: Grok의 계획·구현·테스트 검수·최종 판단/자동 보완 연계. 단계별 기록과 재시작 중복 방지, 취소, 실제 CLI 기록, HUD 프로세스 상세/다시보기 지원. 실제 네 CLI로 격리 예제의 테스트4개와 Grok4단계 PASS 확인. 공백 Python 경로, 빠른 보완의 바이트코드 캐시, 터미널 닫기 후 빈 HTTP 응답 문제를 보완했습니다.

자동 단계 분석은 요구사항·검증 요약만 전달하며 웹 검색과 프로젝트 파일 도구를 사용하지 않습니다.
Grok은 분석·권고만 제공하고 실제 테스트·독립 Reviewer·HEAD의 판정은 유지합니다.
기본값은 Grok 분석 실패 시 오류를 표시하고 기존 검수 흐름을 계속합니다.
필수 분석으로 운영하려면 config.yaml의 grok_pipeline.required를 true로 지정할 수 있습니다.
실패한 테스트를 실제로 실행한 뒤 보완하여 통과하는 회귀 검증과 단계 기록·취소·재시작 중복 방지·다시보기 UI를 검사했습니다.
0.3.6 기본 pytest: 668개 통과, 별도 실행용 통합 검사 2개 제외. HUD JavaScript 검사 5종 통과.
